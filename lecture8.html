File Handling in Python

Read from and write to files on disk. Manage the data flow between your program and the file system safely and efficiently using Python's built-in file tools.

open() read write append close() with statement file modes
📁

What Is File Handling?

File handling is the ability to create, open, read, write, and close files stored on your computer's disk. It lets your program persist data beyond a single run — saving results, reading configuration, logging events, and more.

OperationWhat it does
CreatingMake a new file on disk
OpeningEstablish a connection between your program and a file
ReadingPull content from the file into your program
WritingPush data from your program into the file
ClosingRelease the file resource so others can use it
🔓

Opening a File — Modes

The built-in open() function requires a file path and a mode. The mode controls what you're allowed to do with the file.

"r"
Read only
Opens for reading. File must already exist — raises an error otherwise.
"w"
Write
Opens for writing. Creates a new file or erases the existing one first.
"a"
Append
Opens for appending data to the end. Creates the file if it doesn't exist.
"r+"
Read + Write
Opens for both reading and writing. File must already exist.
"w+"
Write + Read
Opens for writing and reading. Creates or truncates the file.
"a+"
Append + Read
Opens for appending and reading. Creates the file if it doesn't exist.
📖

Reading a File

Open the file in read mode, call file.read() to get all content as a single string, then close it. You can also use readline() to read one line at a time, or readlines() to get a list of all lines.

reading a file
file = open("DS502.txt", "r") content = file.read() # entire file as one string print(content) file.close() # Read line by line file = open("DS502.txt", "r") for line in file: print(line.strip()) file.close()
✍️

Writing to a File

Open the file in write mode "w" and call file.write(). Be careful — write mode erases any existing content first. To add without erasing, use append mode instead.

writing to a file
# Write mode — creates or overwrites file = open("DS502.txt", "w") file.write("Hello, World!\n") file.write("DS502 - Programming Foundation\n") file.close()
append mode — add without erasing
# Append mode — preserves existing content file = open("DS502.txt", "a") file.write("This will add this line\n") file.close()
⚠️ Write mode erases first! If you open an existing file with "w", all its previous content is gone immediately. Use "a" to append safely.
🔒

Closing a File — The with Statement

Always close files after use to release system resources and ensure your data is saved. The with statement is the preferred approach — it automatically closes the file when the block exits, even if an error occurs.

manual close vs. with statement
# Manual — easy to forget close() file = open("DS502.txt", "r") content = file.read() print(content) file.close() # must remember this! # Better — with handles closing automatically with open("DS502.txt", "r") as file: content = file.read() print(content) # file is automatically closed here — even on error
✅ Best practice: Always use the with open(...) as file: pattern. It prevents resource leaks and file corruption, and your code is shorter and safer.
⚖️

Advantages & Disadvantages

✅ Advantages
  • Versatile — create, read, write, append, rename, delete
  • Flexible — works with text files, binary files, CSV, and more
  • User-friendly — simple, readable API with open()
  • Cross-platform — same code runs on Windows, Mac, and Linux
❌ Disadvantages
  • Error-prone — permissions, missing files, and locks can cause failures
  • Security risks — user input in file paths can expose sensitive data
  • Complexity — advanced formats (binary, Excel) require more care
  • Performance — slower than in-memory operations, especially for large files
🧪

Putting It Together

A complete workflow: write data, append more, then read it all back.

write → append → read
# 1. Write initial content with open("students.txt", "w") as f: f.write("Ahmed\n") f.write("Salma\n") # 2. Append a new student with open("students.txt", "a") as f: f.write("Omar\n") # 3. Read all students back with open("students.txt", "r") as f: names = f.readlines() print("Enrolled students:") for i, name in enumerate(names, 1): print(f" {i}. {name.strip()}")
